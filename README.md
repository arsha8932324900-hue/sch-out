# اپ موبایل کارنامه (PWA)

اپ نصب‌شدنی با ظاهر «دفتر مدرسه» (کاغذ شطرنجی، مهر سطح، ستاره‌ها، یادداشت‌های زرد، سکوی برترین‌ها؛ حالت تیره هم دارد) (بدون APK و بدون هشدار «ناامن») که داده‌ی رمزگذاری‌شده‌ی مدرسه را از GitHub می‌خواند، روی گوشی رمزگشایی می‌کند و نمایش می‌دهد: نمای کلی، رتبه‌بندی، جستجوی دانش‌آموز، کارنامه‌ی فردی با نمودار. آفلاین هم آخرین داده را نشان می‌دهد.

## راه‌اندازی (یک‌بار، حدود ۱۰ دقیقه)

1. در GitHub یک ریپوی **عمومی** بسازید (مثلاً `school-app`)؛ Pages رایگان فقط برای ریپوی عمومی کار می‌کند. همه‌ی فایل‌های این پوشه را در آن آپلود/push کنید.
2. ریپو ← Settings ← Pages ← Source را روی **GitHub Actions** بگذارید. بعد از چند دقیقه آدرس `https://USERNAME.github.io/school-app/` ساخته می‌شود (تب Actions وضعیت را نشان می‌دهد).
3. **جای داده** (یکی را انتخاب کنید):
   - **ریپوی خصوصی جدا** (امن‌تر): در پنل مدرسه همان ریپو را برای همگام‌سازی بدهید. در اپ، هر کاربر یک توکن فقط‌خواندنی (Fine-grained، فقط همان ریپو، `Contents: Read-only`) وارد می‌کند.
   - **همین ریپوی عمومی**: در پنل مدرسه ریپوی اپ را بدهید. فایل `data.enc.json` عمومی می‌شود ولی رمزگذاری‌شده است؛ پس رمز داده باید **بلند** باشد (۱۲ کاراکتر یا بیشتر). این فایل در سایت منتشر نمی‌شود و آپلودش هم ساخت دوباره‌ی سایت را راه نمی‌اندازد.
4. در `config.js` مقدار `repo` را بنویسید (مثلاً `"myschool/school-data"`) تا کاربران فقط رمز داده را وارد کنند.
5. در پنل مدیریت مدرسه: «تنظیمات ← ☁️ همگام‌سازی» ← «همگام‌سازی همین حالا». نام فایل باید با `path` در `config.js` یکی باشد (`data.enc.json`).

## نصب روی گوشی
- **اندروید (Chrome):** آدرس را باز کنید ← منو ← «Install app» یا «Add to Home screen».
- **آیفون (Safari):** دکمه‌ی Share ← «Add to Home Screen».

## امنیت
- داده با AES-256-GCM رمز شده و فقط روی گوشی (WebCrypto) باز می‌شود؛ رمز داده هرگز به جایی ارسال نمی‌شود.
- رمز فقط اگر کاربر «به‌خاطر سپردن» را بزند روی همان دستگاه می‌ماند. توکن (در صورت وارد کردن) هم فقط روی همان دستگاه ذخیره می‌شود.
- «خروج و پاک‌کردن داده‌ی این دستگاه» در تنظیمات اپ، رمز، توکن و داده‌ی کش‌شده را پاک می‌کند.
- یک رمز برای کل داده است؛ هر کس رمز را داشته باشد همه‌ی دانش‌آموزان را می‌بیند. برای دسترسی جدا به‌ازای هر دانش‌آموز باید فایل جدا با رمز جدا ساخته شود.

## فایل‌ها
`index.html` (اپ) · `config.js` (تنظیمات) · `sw.js` (کش آفلاین) · `manifest.webmanifest` و آیکون‌ها · `fonts/` (وزیرمتن، مجوز OFL) · `.github/workflows/pages.yml` (انتشار خودکار).
اگر `index.html` یا `config.js` را عوض کردید، اپ را ببندید و دو بار باز کنید تا نسخه‌ی جدید بیاید (برای اجبار فوری، عدد نسخه‌ی `V` را در `sw.js` بالا ببرید).
